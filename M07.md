provider execution, cancellation budgets and cleanup validation are retained.
Queue dispatch requires explicit action; restart/restore invalidates approvals.

Git worktrees share metadata and **are not OS security sandboxes**. Providers and
approved test runners retain OS-user filesystem/network privileges. Whole-provider
isolation remains unavailable and fails closed when required. There are no hard
CPU/RAM/disk/network quotas. Redaction is heuristic; backups/logs may contain private
code/task data and exports are unencrypted. No real provider was run against a
user repository. See SECURITY-MODEL.md for the complete trust boundary.

`gh api repos/foti-antonio/forma/environments` returned no configured environments;
`gh secret list --repo foti-antonio/forma --json name` returned no repository
secrets. Only names/metadata were queried; no credential values were retrieved.

signature, Developer ID, notarization or clean-machine trust pass is claimed.
The prepared signed workflow has been statically validated, not executed.
No OS security controls were bypassed.

## Remaining blockers and approval boundary

Required before unrestricted public distribution:

- Provision the protected `release-signing` environment, required reviewers with
  self-review disabled, approved-tag deployment restrictions, tag creation rules,
  Windows signing credentials and Apple Developer ID/notarization credentials.
  Run the protected path and independently verify signatures/tickets and hashes.
- Complete clean-machine interactive installation, rendered functional QA,
  upgrade/restart/uninstall/data-retention and trust behavior on Windows x64,
  Intel macOS and Apple Silicon macOS. Hosted DEB installation/removal is now
  proven, but clean supported Linux desktop hardware/graphics/shutdown testing is
  still required for the observed WebKit process-exit risk. Extraction alone is
  not substituted for installation.
- Resolve the inherited macOS 10.15 packaging floor against the frontend's
  [Tailwind 4 modern-engine requirements](https://tailwindcss.com/docs/compatibility).
  Native metadata is not evidence of older WKWebView support; choose/test the
  actual minimum macOS release before public distribution.
- Broaden AppImage portability/interactive coverage on the intended support
  baseline. Direct FUSE rendering/persistence on Omarchy and FUSE-free hosted
  Ubuntu execution now pass; they do not prove every distribution or GPU.
- Review known host-execution/backup privacy limits and the final signed candidate
  inventory before release approval. Preserve backups before upgrades.

Optional follow-ups: authenticated Claude integration, concurrent real-provider
performance/large-repository/resource-pressure benchmarks, generated IPC types,
stronger externally designed OS containment and backup encryption/retention.
These are not silently represented as completed beta features.

Final approval checklist:

Successful CI, a prepared draft workflow or branch publication grants none of
