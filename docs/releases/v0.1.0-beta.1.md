# Forma v0.1.0-beta.1

Unpublished release candidate for the first public beta. Intended for evaluation
with backed-up data and trusted repositories. See [M07.1](../../M07.1.md) for actual
build evidence, artifact links, platform gaps and the final approval checklist.

Forma is a local-first desktop project manager with workspaces, projects, issues,
labels, subtasks, List/Kanban views, Git inspection, opt-in approved coding agent
runs, persistent task queues, independent tests and native backup/restore.
No Forma account or server is required. No automatic commits, merges or pushes.

## Installation and integrity

See [INSTALLATION](../INSTALLATION.md) for architecture selection and native
installation. Download an installer and its matching `SHA256SUMS` from the same
candidate run; verify before opening. Checksums detect changed downloads; they do
not establish publisher identity. Candidates are not automatically published.

| Platform            | Installer target         | Formats       |
| ------------------- | ------------------------ | ------------- |
| Linux x86_64        | x86_64-unknown-linux-gnu | AppImage, DEB |
| Windows x64         | x86_64-pc-windows-msvc   | NSIS EXE, MSI |
| Intel macOS         | x86_64-apple-darwin      | DMG           |
| Apple Silicon macOS | aarch64-apple-darwin     | DMG           |

Minimum candidate macOS: **15.0** on Intel and Apple Silicon. Older macOS
versions are unsupported; see the compatibility rationale in INSTALLATION.

## Data and upgrade

The application identifier stays `dev.forma.desktop`. Existing data is retained;
startup applies transactional migrations through schema 6. Export a backup first.
This beta exports format 4 and imports exact supported format 1–4 snapshots;
older builds cannot read newer backups. Restoring clears executable/repository
permissions, interrupts unfinished work and never resumes queued execution.
Uninstalling the program is separate from deleting app data. See [BACKUP](../BACKUP.md).

## Known limitations and trust

Unsigned Windows and ad-hoc signed macOS candidates are internal evaluation
artifacts, not trusted public installers. Developer ID/notarization and Windows
Authenticode require protected credentials and native verification. Do not
remove quarantine, bypass Gatekeeper or disable OS security to install a beta.
Native interactive installer/functional QA coverage is recorded per platform in
M07; successful compilation or initialization alone does not prove it.

Agents/test runners execute as your OS user. Git worktrees are not security
sandboxes. Trust executables and repositories, review exact approvals and inspect
results before manual integration. Whole-provider OS isolation is unavailable;
requiring it blocks execution. Logs may expose private content despite heuristic
redaction. Backups are not encrypted and exclude repository/worktree contents.
The Linux development host produced WebKit subprocess shutdown core dumps while
using an extracted runtime with host graphics libraries; supported clean-desktop
graphics/shutdown verification remains a distribution gate. See M07 for the
investigation and the separately passing hosted package lifecycle tests.
Authenticated Claude completion remains unverified. There is no automatic updater.
Read [SECURITY-MODEL](../SECURITY-MODEL.md) before enabling agents.

Report reproducible beta defects using the repository issue templates; omit
private backups, credentials and raw agent logs. See [TROUBLESHOOTING](../TROUBLESHOOTING.md).
